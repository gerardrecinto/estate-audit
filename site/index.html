estate-audit

Audit a mixed Linux and Windows server estate: patch age, certificate expiry, SAN and NAS volume forecasts, LDAP account hygiene and a tamper-evident maintenance log.

See the sample report (synthetic data: 12 servers, one LDAP dump). Source and README.

git clone https://github.com/gerardrecinto/estate-audit && cd estate-audit
python3 -m venv .venv && . .venv/bin/activate && pip install -e .
estate-audit check data/sample_inventory.json --ldif data/sample.ldif

Lab scale: checked on CI runners with synthetic data, not on a real fleet.
